# Bow-and-Heart

A small, browser-based interactive experience built with **HTML, CSS, and JavaScript**. Bow-and-Heart presents a playful visual scene with a heart-and-bow theme and is designed to run as a lightweight static web page.

## Features

- Pure HTML, CSS, and JavaScript
- No framework, package manager, or build step required
- Lightweight and easy to customize
- Works in modern desktop and mobile browsers

## Run locally

Clone the repository and open `index.html` in a browser:

```bash
git clone https://github.com/awakenedarpit/Bow-and-Heart.git
cd Bow-and-Heart
```

For the most reliable browser behavior, serve the directory with a local static server:

```bash
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Project structure

```text
Bow-and-Heart/
├── index.html   # Page structure, styling, and interaction
└── README.md    # Project documentation
```

## Customization

Edit `index.html` to change the page content, colors, layout, or animation behavior. Because this is a static project, changes can be previewed by refreshing the page after saving.
